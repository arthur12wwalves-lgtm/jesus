# Meu Controle Financeiro

Web app simples para registrar entradas e saídas de dinheiro, calcular totais e mostrar o saldo atual.

## Como publicar

1. Crie um repositório no GitHub.
2. Envie `index.html` e `README.md` para o repositório.
3. Na Vercel, escolha **Add New → Project** e importe o repositório.
4. Para este projeto não é necessário banco de dados nem variáveis de ambiente.
5. Clique em **Deploy**.
